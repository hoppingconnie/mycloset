# 👗 My Closet — AIコーディネート提案アプリ

手持ちの服を登録すると、気温・シーンに合わせたコーディネートを提案してくれる、パーソナルなワードローブ管理アプリです。

---

## このアプリについて

AIが提案したコーディネートをそのまま着ることを目的としていません。

> 「こんな組み合わせもあるんだ」  
> 「今日はこれをベースに考えてみよう」

というアイディアやヒントとして活用いただくことを想定しています。  
服選びにかかる時間や迷いを減らしながら、手持ちの服をより楽しく活用できることを目指しています。

---

## おすすめの使い方

- AIの提案をそのまま着る必要はありません。アイディアやヒントとしてお楽しみください。
- 最初はトップス・ボトムス・羽織りなど **30着程度** 登録すると、提案の幅が広がります。よく着る服から登録し、隙間時間に少しずつ追加するのがおすすめです。
- 推奨は **100着以上** です。

---

## 主な機能

| 機能 | 説明 |
|------|------|
| コーデ提案 | 最高・最低気温とシーン（会社・旅行など）を入力すると3パターンを提案 |
| フィードバック | 好き・褒められた・寒かったなどを記録し、次回提案に反映 |
| 色ルール | 避けたい組み合わせ・好きな組み合わせを設定 |
| 服管理 | カテゴリ・厚さ・季節・用途タグで整理。写真の登録も可能 |
| データ管理 | JSONでエクスポート／インポート。機種変更やバックアップに対応 |

---

## 技術スタック

- **フレームワーク**: Next.js (App Router) + TypeScript
- **スタイリング**: Tailwind CSS v4
- **データ保存**: ブラウザの localStorage（サーバー不要）
- **ホスティング**: Vercel

データはすべて **使用しているデバイスの中だけ** に保存されます。外部サーバーには送信されません。

---

## ローカルでの起動

```bash
npm install
npm run dev
```

ブラウザで [http://localhost:3000](http://localhost:3000) を開いてください。

---

## デプロイ

GitHub リポジトリを Vercel に連携するだけで自動デプロイされます。  
localStorage を使用しているため、サーバーサイドの設定は不要です。
